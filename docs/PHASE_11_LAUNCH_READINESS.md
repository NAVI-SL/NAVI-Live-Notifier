## Prioritized release blockers

1. **Major correctness:** Phase 10 M01 retained YouTube candidates behind 50 uploads can remain unchecked. Current source unchanged; 335 passing baseline tests do not close it. Fix with bounded fair candidate checking, budget accounting and focused regressions.
2. **Major acceptance:** actual two-platform starts/receipts, full auth/install/settings journey, approved two-server isolation, repeat/reconnect counts and latency/soak evidence absent. Public API authentication is insufficient.
3. **Major operations:** database/container/TLS unavailable; real runtime roles, persistence, restart/restore/rollback and alerts unverified. Restore local services safely, not by resetting volumes.
4. **Major public access/capacity:** no reviewed public signup/admission policy, hard guild cap or demonstrated public load protection. Private beta retains allowlist and manually approved targets; public bot installations would not be limited by that account allowlist alone.
5. **Major policy/data lifecycle:** public contacts and legal identity unset; manual deletion/backup expiry/indefinite deduplication metadata need tested decisions. Current notices cannot be called public-ready merely because drafts exist. No Sri Lankan or global legal/platform compliance certification is made.
6. **Residual/minor:** four moderate advisories, floating/unscanned images, limited readiness/CSP, host-local Gateway ownership and earlier registration refresh/error edges; see Phase 10 audit.

**Decision: NO-GO for public release and for claiming private-beta acceptance.** Phase 11 preparation is reviewable; the approved next launch remains a restricted private beta after the above relevant gates close. No Public Bot toggle, App Directory submission, public deployment, production configuration change, spending or Phase 12 work occurred.
